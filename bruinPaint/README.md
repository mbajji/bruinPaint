# Three Colors

A deliberately constrained drawing app for a creativity-support-tools presentation.

## Run locally

Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Rules

- Initially, only coral, blue, and green are available.
- Draw only freehand lines by clicking and dragging on the canvas.
- Undo removes the most recent stroke; Clear empties the canvas.
- **Hidden rule:** press the spacebar to reveal the extra colors.

The hidden shortcut is intentionally not shown in the app's interface, so you can reveal it during your presentation.
